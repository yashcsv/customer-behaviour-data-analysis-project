Customer Behavior Data Analysis Project 


Made by Yash Singh Thakur 
This is an end-to-end data analysis project where I explored customer shopping behavior 
using Python, SQL, and Power BI. 

The main idea behind this project was to take a raw dataset, clean it, analyze it, and turn it 
into useful insights and dashboards, similar to what a data analyst would do in a real 
company. 

I built this project mainly to practice real-world data analytics skills and add a solid project 
to my data analytics portfolio. 



Skills Used 
• Python (Pandas, Jupyter Notebook) 
• SQL 
• Power BI 
• Data Cleaning 
• Exploratory Data Analysis 
• Data Visualization 


What I Did in This Project 

Data Cleaning (Python) 
• Loaded and cleaned the dataset using Pandas 
• Handled missing values and prepared the data for analysis 

Data Analysis (SQL) 
• Imported the data into a SQL database 
• Wrote SQL queries to analyze customer purchases and trends
